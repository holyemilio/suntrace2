# SunTrace — for developers

This page is for people changing the code. How the app works for its users is
in the [README](../README.md) and the [user manual](user-manual/user-manual.md);
how the estimate is computed, formula by formula, is in [method.md](method.md).

Vanilla JS, native ES modules, **no build step, zero runtime dependencies**.
Leaflet 1.9.4 and the fonts are self-hosted in `vendor/`.

## Running it locally

The `.html` files can't be opened with a double click: ES modules and
geolocation need `http://localhost`.

```bash
./start.command          # macOS: server on :8000 with Cache-Control: no-store
# or
python3 -m http.server 8000
```

`index.html` is the landing page, `app.html` the app.

## Tests

Needs Node.js 18+.

```bash
npm install                        # suncalc and Playwright, for tests only
npm test                           # unit: solar engine, cost, geometry/shadows, prices, zones
npx playwright install chromium    # once
npm run test:e2e                   # e2e: the app in a real browser, external APIs mocked
```

CI (`.github/workflows/ci.yml`) reruns them on every push, plus a check that
every key in `src/i18n.js` exists in both Italian and English.

## Project rules

- Every visible text goes through `data-i18n` (or `-ph`, `-aria`, `-title`) and
  has its key in **both** languages in `src/i18n.js`.
- No CDNs, no new runtime dependencies, no bundler.
- Every constant in the calculation has a source in `docs/method.md`. A value
  that can't be verified doesn't enter the calculation.
- Every colour is a token in `src/tokens.css`, defined for light and dark.
- Before touching the layout or the map, read the pitfalls in
  [project-status.md](project-status.md).
- Repository docs, comments and commit messages are in English.

## Prices

They update themselves every month (`.github/workflows/update-prices.yml`). To
regenerate them by hand: `python3 scripts/update_prices.py` (`--check` prints
without writing). Details in
[method.md, "How prices are updated"](method.md#how-prices-are-updated).

## Brand and link preview

Logo, symbol and icons are in `docs/brand/`. The link-preview image
(`og-image.png`, 1200×630) is regenerated by opening `docs/brand/og-source.html`
from the local server and taking a 1200×630 screenshot (e.g. with Playwright).
