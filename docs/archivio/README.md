# Archivio — documenti della versione 3

Questi documenti descrivono SunTrace 2 fino alla versione 3.1.2, quando l'app
dava un **Comfort Rate** a stelle e una stima delle temperature stagionali.
Dalla versione 4.0.0 l'app stima invece il **costo del riscaldamento** in euro
e quei contenuti non sono più validi.

Restano qui per la storia del progetto. Per la versione attuale:

- come si usa: [README](../../README.md)
- come si calcola: [metodo.md](../metodo.md)
- come si sviluppa: [sviluppo.md](../sviluppo.md)
